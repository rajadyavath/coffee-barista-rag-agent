# ☕ Coffee Shop AI Barista

A customer-facing AI Barista built using Google ADK and Gemini on Vertex AI.

## Features

- Google ADK Agent
- Gemini 2.5 Flash
- Firestore Vector Search
- Retrieval-Augmented Generation (RAG)
- Streamlit Chat UI
- Cloud Run Deployment
- Semantic Search using text-embedding-004

## Architecture

User
↓
Streamlit
↓
Google ADK
↓
Gemini
↓
Firestore Vector Search
↓
Coffee Menu

## Technologies

- Python
- Google ADK

- Gemini
- Firestore
- Firestore Vector Search
- Cloud Run
- Streamlit
